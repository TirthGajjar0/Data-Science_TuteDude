# Assignment 5 - Titanic Survival Prediction

## Overview

Built a Naive Bayes classification model to predict passenger survival using the Titanic dataset from Kaggle. This project covers the complete workflow from data preprocessing to model evaluation.

## What I Did

* Explored and cleaned the dataset
* Handled missing values
* Encoded categorical features
* Split data into training and testing sets
* Built a Gaussian Naive Bayes model
* Performed hyperparameter tuning
* Evaluated model performance

## Results

| Model          | Accuracy |
| -------------- | -------: |
| Initial Model  |   77.65% |
| Improved Model |   78.21% |

The improved model achieved better performance after feature refinement and tuning.
