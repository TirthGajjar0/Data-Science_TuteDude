# Assignment 7 - Heart Disease Prediction

## Overview

This case study focuses on predicting heart disease using multiple machine learning classification algorithms. The project includes data preprocessing, feature scaling, model training, hyperparameter tuning, and comparative evaluation using a healthcare dataset.

## What I Did

* Explored and cleaned the dataset
* Handled missing values
* Standardized numerical features
* Built and compared multiple classification models:

  * Logistic Regression
  * K-Nearest Neighbors (KNN)
  * Decision Tree
  * Random Forest
  * Support Vector Machine (SVM)
* Performed hyperparameter tuning using GridSearchCV
* Evaluated models using multiple classification metrics

## Results

| Model                            |   Accuracy |
| -------------------------------- | ---------: |
| Logistic Regression              |     78.69% |
| KNN                              |     80.33% |
| Decision Tree                    |     78.69% |
| Random Forest                    |     80.33% |
| **Support Vector Machine (SVM)** | **83.61%** |

SVM achieved the highest accuracy and overall best classification performance among the evaluated models.
