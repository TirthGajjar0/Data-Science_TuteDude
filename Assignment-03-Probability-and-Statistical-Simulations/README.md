# Assignment 3 - Probability and Statistical Simulations

## Overview

This assignment explores fundamental concepts of probability and statistics through simulations and data visualization using Python. The project demonstrates how theoretical probability concepts can be verified experimentally using random sampling techniques.

## Topics Covered

### Probability Basics
- Coin Toss Simulation
- Dice Roll Simulation
- Experimental Probability
- Probability Estimation

### Conditional Probability
- Conditional Events
- Bayes' Theorem Verification
- Random Sampling Simulations

### Random Variables
- Discrete Probability Distributions
- Empirical Mean
- Variance
- Standard Deviation

### Continuous Probability Distributions
- Exponential Distribution
- Probability Density Functions (PDF)
- Histogram Visualization

### Central Limit Theorem (CLT)
- Uniform Distribution Sampling
- Sample Means Distribution
- CLT Visualization and Analysis

## Libraries Used

- NumPy
- Matplotlib
- Random

- Analyze probability distributions using statistical measures.
