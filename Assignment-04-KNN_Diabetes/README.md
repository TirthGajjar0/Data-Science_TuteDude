# Assignment 4 - Diabetes Prediction Case Study

## Overview

This case study focuses on predicting the likelihood of diabetes using patient health data from the Pima Indians Diabetes Dataset.

The project follows a complete data science workflow, including data exploration, preprocessing, feature scaling, model training, hyperparameter tuning, and performance evaluation using the K-Nearest Neighbors (KNN) algorithm.

## What I Did

### Data Exploration
- Examined dataset structure and feature information
- Checked for missing values and duplicate records
- Performed descriptive statistical analysis

### Data Preprocessing
- Identified hidden missing values represented as zeros
- Replaced invalid values with appropriate missing values
- Imputed missing data using median values
- Prepared the dataset for machine learning

### Feature Scaling
- Applied Min-Max Scaling to normalize feature values
- Improved model performance by ensuring consistent feature ranges

### Machine Learning Model
Implemented:

- K-Nearest Neighbors (KNN)

### Model Optimization
- Applied GridSearchCV for hyperparameter tuning
- Evaluated different values of K
- Tested multiple distance metrics
- Selected the best-performing model configuration

### Model Evaluation
Evaluated model performance using:

- Accuracy Score
- Confusion Matrix
- Classification Report
- Precision
- Recall
- F1 Score
