# Assignment 1 - Employee Management System
# Python Basics

## Overview

This project implements a simple Employee Management System (EMS) using Python. The application allows users to manage employee records through a menu-driven interface and demonstrates the use of dictionaries, functions, control structures, and basic data management techniques.

## Features

- Add new employees
- View all employee records
- Search employees by Employee ID
- Input validation for unique Employee IDs
- Menu-driven console interface

## Concepts Used

- Python Dictionaries
- Functions
- Conditional Statements
- Loops
- User Input Handling
- Data Storage and Retrieval

## Data Structure

Employee information is stored using nested dictionaries:

- Employee ID
- Name
- Age
- Department
- Salary

## Technologies Used

- Python

## Learning Outcomes

- Managing structured data using dictionaries
- Building modular programs with functions
- Implementing menu-driven applications
- Performing data validation and search operations
