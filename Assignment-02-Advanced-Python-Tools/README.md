# Assignment 2 - Advanced Python Tools

## Overview

This assignment introduces essential Python libraries widely used in Data Science and Machine Learning. It covers numerical computing with NumPy, data analysis with Pandas, and data visualization with Matplotlib.

### NumPy
- Array Creation and Manipulation
- Statistical Operations
- Matrix Operations
- Array Reshaping and Slicing
- Random Number Generation

### Pandas
- DataFrame Creation
- Data Exploration
- Summary Statistics
- Data Filtering
- GroupBy Operations
- Data Aggregation
- CSV Export

### Matplotlib
- Line Plots
- Bar Charts
- Pie Charts
- Histograms
- Plot Customization
- Data Visualization Techniques

- NumPy
- Pandas
